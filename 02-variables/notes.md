# Lesson 2: Variables and Data Types

## What is a variable?
A variable is a named container that stores a value in memory. 
Before you use a variable in C, you must declare its type — 
C needs to know what kind of data it will hold.

## Common data types
- `int` — whole numbers (e.g. 5, -12, 100)
- `float` — decimal numbers (e.g. 3.14)
- `char` — a single character (e.g. 'A')
- `double` — decimal numbers with more precision than float

## Declaring a variable
```c
int age;
age = 20;
```
Or in one line:
```c
int age = 20;
```
