# Lesson 14: Final Project — Contact Book

## What we're building
A simple contact book program that lets you add contacts, view 
all contacts, and save them to a file — combining everything 
from lessons 1 through 13: structs, arrays, functions, loops, 
conditionals, and file handling.

## How it works
1. The program stores contacts using a struct (name, phone number)
2. You can add a new contact
3. You can view all saved contacts
4. All contacts are saved to a file so they aren't lost when 
   the program closes

## Concepts used from earlier lessons
- **Structs** (lesson 12) — to hold each contact's data
- **Arrays** (lesson 7) — to store multiple contacts
- **Functions** (lesson 6) — to organize the code into reusable pieces
- **Loops** (lesson 5) — to display all contacts
- **Conditionals** (lesson 4) — to handle the menu choices
- **File handling** (lesson 13) — to save/load contacts
