# Lesson 1: Hello World

## What is C?
C is a programming language created in 1972. It's fast, low-level, 
and forms the foundation of many other languages (C++, Java, Python 
are all influenced by it). Operating systems like Windows and Linux 
are largely written in C.

## What is a compiler?
Computers only understand machine code (1s and 0s). A compiler 
translates the C code you write into machine code the computer 
can run. We'll use a compiler called `gcc`.

## Your first program
