# Learn C Programming

A beginner-friendly course to learn the C programming language, one lesson at a time.

## How to use this repo
- Each folder is one lesson, in order (01, 02, 03...)
- Every lesson has a `notes.md` (explanation) and a `.c` file (code example)
- Compile and run any example with:

```bash
gcc filename.c -o output
./output
```

## Requirements
- A C compiler (gcc). 
  - Windows: install MinGW
  - Mac: install Xcode command line tools
  - Linux: usually pre-installed, or `sudo apt install gcc`
